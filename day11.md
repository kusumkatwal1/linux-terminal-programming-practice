## Linux Directory Structure & Filesystem Hierarchy: 

- The simplified way:

    /       → filesystem root
    /etc    → configuration
    /home   → user homes
    /root   → root user's home
    /usr    → installed system software/resources
    /var    → changing/persistent variable data
    /tmp    → temporary files
    /run    → runtime state
    /dev    → device interfaces
    /proc   → kernel/process virtual filesystem
    /sys    → device/kernel virtual filesystem
    /boot   → boot-related files
    /opt    → optional application software
    /srv    → service-provided data
    /mnt    → temporary/manual mounts
    /media  → removable media
